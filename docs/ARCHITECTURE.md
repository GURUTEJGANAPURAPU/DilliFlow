# DilliFlow architecture

```text
Browser (React + TypeScript + Vite)
        |
        | JSON REST over localhost / configured API base
        v
Python FastAPI service
        |-- Transit query service
        |-- Ticket-demand analytics service
        |-- GTFS-Realtime fetch/decode/cache service
        |
        v
SQLite database (generated by ETL)
        |-- static GTFS tables
        |-- ticket route/hour aggregates
        |-- OD and segment-demand aggregates
        |-- ingestion quality summary

Raw input files (backend/data/raw)
        |-- static GTFS ZIP
        |-- October ticket ZIP

Transport Stack GTFS-Realtime API
        |-- server-side x-api-key only
        v
VehiclePositions.pb (Protobuf)
```

No Lovable Cloud, Supabase or Firebase is required. The browser has no direct access to the Transport Stack secret.
